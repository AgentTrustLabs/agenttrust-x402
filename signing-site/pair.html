Notes: connection uses the official Concordium Browser Wallet API. Ownership is proven by signing a short-lived, single-use, network-bound challenge — the wallet prepends bytes so the message can never be a transaction. Pairing requires the agent to pass the independent CIS-8004 + Agent Card verification (TRUSTED). No private key, recovery phrase, or signature is stored. QR-based (mobile/WalletConnect) pairing is not available in this build — see docs/connect-wallet-agent-pairing.md.
