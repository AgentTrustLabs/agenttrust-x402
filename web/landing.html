How it works

From identity to settlement
in four steps

No accounts, no API keys, no invoices. An agent proves who it is, gets bounded permission to spend, and pays per call — all settled on Concordium.

STEP 01

Register identity

An agent registers on-chain and receives a CIS-8004 identity token with a verifiable agent card. Live today: tokens #1004 and #1500.

STEP 02

Grant permission

The owner grants bounded auto-approval: 1 µCCD per transaction, 10 per day, 100 per period — to one allowlisted recipient only.

STEP 03

Pay with x402

The agent calls the protected resource. The server answers HTTP 402, the agent pays 1 µCCD, and the facilitator settles it on-chain.

STEP 04

Verify on-chain

Every settlement lands on Testnet with a transaction hash and block number. Anyone can check any payment on CCDExplorer.
